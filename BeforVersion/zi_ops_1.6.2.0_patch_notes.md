# ZI-Ops 1.6.2.0

- При массовом обновлении новые версии плагинов с отметкой «Кастомный» скачиваются в папку Custom рядом с программой для ручного переноса собственных изменений.
- Кастомные плагины на сервере не заменяются. Актуальные, более новые и плагины с неопределённой версией по-прежнему пропускаются.
- Существующие файлы в Custom не перезаписываются: при отличающемся содержимом новая копия получает суффикс версии. Повторное сохранение одинакового файла не создаёт дубликат.
- В логе отображаются пути сохранённых исходников и отдельное количество скачанных кастомных плагинов.
