# ZI-Ops 1.5.32.0

- Расширена проверка версий плагинов: теперь можно указывать страницы Codefling, RustPlugin и других сайтов с доступной информацией о версии.
- Исправлено определение версии на сторонних сайтах: номера из описаний, комментариев и зависимостей больше не принимаются за версию самого плагина.
- Количество попыток скачивания по FTP увеличено с 3 до 10. При временной ошибке соединения программа переподключается и повторяет загрузку.
- Добавлены повторные запросы версии при временных сбоях сети и ограничении запросов со стороны сайта — до 10 попыток с паузами.
- Улучшено сопоставление плагинов в списке с файлами на сервере: учитываются имя файла и название плагина.
- Проверка последней версии работает и тогда, когда установленную версию не удалось прочитать.
- В журнале появились пояснения, если не указана страница версии или не удалось прочитать сведения из файла плагина.
