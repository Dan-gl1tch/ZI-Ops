## 1.6.3.0

- Ускорена проверка версий плагинов: FTP и сайты проверяются параллельно, а разные сайты обрабатываются в отдельных очередях.
- Добавлено пакетное получение части версий uMod и повторное использование HTTP/HTTPS-соединений.
- Результаты проверки сохраняются до закрытия программы. При повторной проверке заново скачиваются новые и изменённые файлы; если FTP не предоставляет сведения об изменении, файл проверяется повторно.
- Уменьшена задержка между запросами uMod до двух секунд. При ограничении HTTP 429 интервал увеличивается до трёх секунд с учётом Retry-After.
- Улучшена отзывчивость интерфейса: сообщения лога выводятся пачками, обновления прогресса и размеров окна объединяются, таблица пересортировывается реже.
- Число фоновых исполнителей автоматически подбирается по доступным логическим процессорам. RCON и Query работают отдельно от общей очереди.
- Отключение RCON и проверка ссылки на плагин больше не выполняются в потоке интерфейса.
- Таблица плагинов по умолчанию сортируется по имени файла.
- Проверка FTP показывает папки, файлы и их размеры в понятном виде. Добавлена сводка времени FTP и HTTP в журнал проверки плагинов.
- Исправлены сочетания клавиш в русской и других раскладках Windows. Копирование работает в полях, логах и таблице.
- При появлении новых сообщений лог сохраняет позицию прокрутки, если пользователь читает предыдущие строки.
