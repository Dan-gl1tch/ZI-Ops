# ZI-Ops 1.5.29.0

- Во вкладке «Судная ночь» добавлен настраиваемый список файлов. Для каждой записи можно выбрать файл на компьютере, указать папку на сервере и отметить этапы «Начало» и «Конец».
- При включении Судной ночи устанавливаются файлы для начала и удаляются файлы, отмеченные только для конца. При выключении выполняется обратное действие.
- Если отмечены оба этапа, файл устанавливается при включении и выключении. Записи без галочек не участвуют в операции.
- Программа изменяет только файлы из настроенного списка. Добавлена защита от повторяющихся и некорректных путей.
- Перед заменой или удалением создаются резервные копии в папке JudgmentBackups рядом с программой.
- Новые файлы загружаются и проверяются до удаления старых. При сбое программа пытается восстановить прежние файлы из резервной копии.
- Список файлов сохраняется в настройках и загружается при запуске. После перехода со старой версии файлы нужно добавить в новый список вручную.
