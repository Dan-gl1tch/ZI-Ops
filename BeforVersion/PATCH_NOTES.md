# История изменений ZI-Ops

## 1.5.30.0
- В Настройки добавлена кнопка переключения светлой и тёмной темы.
- Текущая синяя палитра используется как тёмная; светлая тема получила светлый фон, тёмный текст и контрастные цвета статусов.
- Оформление переключается сразу для вкладок, таблиц, полей, логов, подсказок и встроенных памяток; новые элементы создаются в выбранной теме.
- Выбор сохраняется в поле theme файла config.json и восстанавливается при запуске. Конфиги без поля theme используют тёмную тему.
- Проверены обе темы, переключение туда и обратно, цвета логов и тегов таблицы, новые элементы, подсказки, сохранение и восстановление темы при запуске в скрытом интерфейсе Tk.

## 1.5.29.0
- Вкладка Судная ночь переведена на настраиваемый список файлов: Обзор, имя из выбранного файла, папка на сервере, галочки Начало/Конец и удаление записи из списка.
- Включение устанавливает отмеченные для начала файлы и удаляет отмеченные только для конца; выключение выполняет обратное. Две галочки устанавливают файл на обоих этапах, без галочек файл не затрагивается.
- Операции ограничены точными путями активных записей. Папки не очищаются, другие плагины не удаляются; дубли путей и небезопасные пути блокируются.
- Все локальные файлы для установки проверяются и читаются до изменения сервера. Затрагиваемые серверные файлы резервируются в JudgmentBackups рядом с программой, с manifest.json.
- Входящие файлы загружаются и проверяются до удаления противоположного набора. При ошибке программа пытается восстановить прежние файлы; если FTP недоступен, сообщает о необходимости ручного восстановления из резервной копии.
- Новый список сохраняется в config.json. Старые поля сохранены в judgment_legacy, но не исполняются автоматически: после обновления нужно добавить файлы в новый список вручную.
