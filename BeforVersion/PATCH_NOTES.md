# История изменений ZI-Ops

## 1.6.3.0

- Ускорена проверка версий плагинов: FTP и сайты проверяются параллельно, а разные сайты обрабатываются в отдельных очередях.
- Добавлено пакетное получение части версий uMod и повторное использование HTTP/HTTPS-соединений.
- Результаты проверки сохраняются до закрытия программы. При повторной проверке заново скачиваются новые и изменённые файлы; если FTP не предоставляет сведения об изменении, файл проверяется повторно.
- Уменьшена задержка между запросами uMod до двух секунд. При ограничении HTTP 429 интервал увеличивается до трёх секунд с учётом Retry-After.
- Улучшена отзывчивость интерфейса: сообщения лога выводятся пачками, обновления прогресса и размеров окна объединяются, таблица пересортировывается реже.
- Число фоновых исполнителей автоматически подбирается по доступным логическим процессорам. RCON и Query работают отдельно от общей очереди.
- Отключение RCON и проверка ссылки на плагин больше не выполняются в потоке интерфейса.
- Таблица плагинов по умолчанию сортируется по имени файла.
- Проверка FTP показывает папки, файлы и их размеры в понятном виде. Добавлена сводка времени FTP и HTTP в журнал проверки плагинов.
- Исправлены сочетания клавиш в русской и других раскладках Windows. Копирование работает в полях, логах и таблице.
- При появлении новых сообщений лог сохраняет позицию прокрутки, если пользователь читает предыдущие строки.

## 1.6.2.0

- При массовом обновлении новые версии плагинов с отметкой «Кастомный» скачиваются в папку Custom рядом с программой для ручного переноса собственных изменений.
- Кастомные плагины на сервере не заменяются. Актуальные, более новые и плагины с неопределённой версией по-прежнему пропускаются.
- Существующие файлы в Custom не перезаписываются: при отличающемся содержимом новая копия получает суффикс версии. Повторное сохранение одинакового файла не создаёт дубликат.
- В логе отображаются пути сохранённых исходников и отдельное количество скачанных кастомных плагинов.

## 1.6.1.0

- «Обновить все» заменяет только плагины с подтверждённой новой версией. Актуальные, более новые и кастомные плагины пропускаются.
- Перед обновлением установленная версия заново читается с сервера. При неизвестной версии, отсутствии страницы или невозможности прочитать файл замена не выполняется.
- Версия скачанного .cs проверяется перед загрузкой: файл без новой версии не заменяет установленный плагин.
- Добавлены паузы между запросами к каждому сайту и кэш результатов проверки версий на пять минут.
- Обработка HTTP 429 и временных ошибок сети распространяется на скачивание плагинов. Программа соблюдает Retry-After, увеличивает паузы и временно прекращает запросы к сайту после повторяющегося ограничения.
- Обновлены пояснения массового обновления во вкладке «Плагины».

## 1.6.0.0

- Во вкладке RCON добавлена панель Query рядом с консолью: название сервера, карта, онлайн, лимит игроков, время ответа и версия сервера.
- При открытии вкладки RCON данные запрашиваются сразу, затем обновляются каждые 10 секунд. При переходе на другую вкладку обновление останавливается.
- Query работает независимо от подключения RCON. При отсутствии ответа показываются последние полученные данные и время их обновления.
- В настройках добавлены отдельные поля адреса и Query-порта. Если адрес не указан, используется адрес RCON.
- В ручном вводе RCON добавлены подсказки стандартных команд с описаниями и примерами. Поиск работает по названию и его части: например, seed находит server.seed.
- Подсказки выбираются стрелками, клавишей Tab или мышью. Выбор заполняет строку; команда отправляется по Enter или кнопке «Отправить». Esc закрывает подсказки.
- Добавлена прокрутка настроек для удобной работы при небольшом размере окна.

## 1.5.32.0

- Расширена проверка версий плагинов: теперь можно указывать страницы Codefling, RustPlugin и других сайтов с доступной информацией о версии.
- Исправлено определение версии на сторонних сайтах: номера из описаний, комментариев и зависимостей больше не принимаются за версию самого плагина.
- Количество попыток скачивания по FTP увеличено с 3 до 10. При временной ошибке соединения программа переподключается и повторяет загрузку.
- Добавлены повторные запросы версии при временных сбоях сети и ограничении запросов со стороны сайта — до 10 попыток с паузами.
- Улучшено сопоставление плагинов в списке с файлами на сервере: учитываются имя файла и название плагина.
- Проверка последней версии работает и тогда, когда установленную версию не удалось прочитать.
- В журнале появились пояснения, если не указана страница версии или не удалось прочитать сведения из файла плагина.

## 1.5.29.0

- При включении Судной ночи устанавливаются файлы для начала и удаляются файлы, отмеченные только для конца. При выключении выполняется обратное действие.

- Перед заменой или удалением создаются резервные копии в папке JudgmentBackups рядом с программой.
- Новые файлы загружаются и проверяются до удаления старых. При сбое программа пытается восстановить прежние файлы из резервной копии.
- Список файлов сохраняется в настройках и загружается при запуске. После перехода со старой версии файлы нужно добавить в новый список вручную.
