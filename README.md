# ZI-Ops — ZombiIsland Operations

![ZI-Ops](https://i.postimg.cc/HsnTF6Zm/Chat-GPT-Image-19-sent-2026-g-12-54-06.png)

Текущая версия: **1.6.2.0**.

ZI-Ops — программа для управления сервером Rust с Windows. В одном окне можно провести вайп, переключить файлы для судной ночи, отправить команду через RCON и проверить версии плагинов.

Файлы сервера доступны через FTP/FTPS, команды отправляются через WebRCON. Для публичного статуса используется Query, для генерации карт — RustMaps.

## Возможности

- **Вайп.** Удаление выбранных файлов и очистка папок, подготовка `server.cfg` с новым seed и размером карты. Перед запуском программа показывает список действий и полные пути.
- **Судная ночь.** Список файлов с отдельными отметками для начала и конца ночи. Можно настроить установку и удаление плагинов или конфигураций. Меняются только файлы из списка; перед переключением создаются их резервные копии.
- **RCON.** Быстрые команды, ручной ввод с подсказками и ответы сервера в консоли.
- **Query.** Название сервера, карта, онлайн, версия и задержка запроса. Данные обновляются, пока открыта вкладка RCON.
- **Плагины.** Проверка установленных версий, сортировка таблицы и обновление по заданным ссылкам. Обновляются только устаревшие версии. Новые версии кастомных плагинов сохраняются в папку `Custom` для доработки; на сервер они автоматически не загружаются. Список источников можно сохранить или загрузить из JSON.
- **RustMaps.** Проверка карты по seed и размеру, отправка запроса на генерацию с API-ключом вашего аккаунта.

Настройки и списки сохраняются между запусками. В программе есть светлая и тёмная тема.

## Скачать и начать работу

Сборки для Windows ищите в [Releases](https://github.com/Dan-gl1tch/ZI-Ops/releases) и в [Telegram-канале](https://t.me/DanStudios47).

1. Запустите `ZI-Ops.exe` и откройте «Настройки».
2. Укажите данные из панели хостинга для нужных функций: FTP для файлов, RCON для команд, Query для статуса. У этих подключений могут быть разные порты.
3. Проверьте FTP и базовую папку. Для RCON подключитесь и нажмите «Проверить».
4. Сохраните настройки.

Перед вайпом проверьте пути удаления и сделайте резервную копию нужных данных. Если хостинг задаёт seed и размер карты через свою панель, менять их нужно там.

Подробные инструкции по каждой вкладке — в [документации](DOCUMENTATION.md). Что изменилось в версиях — в [истории изменений](BeforVersion/PATCH_NOTES.md).

## Обновление плагинов

Для проверки версии нужна страница конкретного плагина, а для установки — прямая ссылка на `.cs`-файл. Эти ссылки указываются отдельно. Если сайт требует вход или покупку, обычная ссылка может не подойти для скачивания.

«Обновить все» сравнивает версию установленного на сервере файла с версией на странице плагина. Актуальные плагины и версии новее опубликованной пропускаются. Если версию определить не удалось, замена не выполняется. Перед загрузкой на сервер программа также проверяет версию в скачанном `.cs`-файле.

Для плагинов с вашими изменениями поставьте галочку «Кастомный». Их новые версии скачиваются в папку `Custom` рядом с программой: можно перенести патч и затем вручную установить файл на сервер. Галочки сохраняются в `config.json`.

При временных ошибках сети и ответе «слишком много запросов» программа делает до 10 попыток с паузами. Повторная проверка уже полученных версий использует кратковременный кэш, чтобы уменьшить число запросов.

## Запуск из исходников

Нужен Python с Tkinter. Установите пакет для RCON и запустите программу:

```bash
python -m pip install websocket-client
python zi_ops.py
```

Для сборки EXE используется `build.bat`:

```bash
python -m pip install pyinstaller websocket-client
build.bat
```

В папке сборки должны находиться `zi_ops.py`, `ZI-Ops.ico` и `zi_ops_version.txt`. Готовый файл появится в `dist/ZI-Ops.exe`.

## Данные доступа

`config.json` рядом с программой содержит сохранённые настройки, в том числе пароли FTP/RCON и RustMaps API Key. Они хранятся без шифрования. Не добавляйте этот файл на GitHub и не отправляйте вместе с программой: получатель сможет прочитать данные доступа и подключиться к серверу.
