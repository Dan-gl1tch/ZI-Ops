# История изменений ZI-Ops

## 2.0.8 — 26 ноября 2026

Переход Windows-приложения с Python / CustomTkinter на Kotlin / Compose Desktop. Android пока не поддерживается.

### Интерфейс

- Воссозданы вкладки и оформление прежней программы, добавлены светлая и тёмная темы.
- Порядок вкладок: вайп, судная ночь, RCON, консоль сервера, плагины, поддержка, настройки.
- Одноцветные значки вкладок, компактные переключатели кастомных плагинов с центрированным крестиком.
- Расширена панель «Важное», добавлено окно результата проверки FTP.
- Раздельная высота логов вайпа, судной ночи и плагинов; RCON и консоль заполняют оставшуюся область.
- Новый значок ZI для окна приложения и Windows-сборки; ICO содержит размеры 16–256 пикселей.

### Настройки

- Внутреннее хранилище `%LOCALAPPDATA%/ZI-Ops/config.json` вместо обязательного JSON рядом с EXE.
- Автоматический перенос старого файла при первом запуске, без удаления исходника.
- Сохранение при штатном закрытии, запись через временный файл.
- Импорт и экспорт текущих настроек в JSON.

### Сервер и плагины

- Перенесены FTP/FTPS, WebRCON, Query, вайп, переключение файлов судной ночи и RustMaps.
- Ответы на команды RCON отделены от самостоятельных сообщений сервера.
- Подсказки команд Rust → Oxide → Carbon, пакетная отправка через `;;`.
- Таблица версий и счётчик проверенных плагинов.
- Статусы «Актуален», «Обновление», «Неизвестно», «Сверх последнего».
- Защита кастомных плагинов: новые исходники сохраняются для ручной доработки.
- Общая очередь запросов по хостам, паузы и до трёх повторов при HTTP 429 с учётом `Retry-After`.

### Сборка и репозиторий

- Добавлены Kotlin-исходники, ресурсы, Gradle Wrapper и батник для Windows.
- Режимы сборки папки приложения, установщика, запуска и встроенных проверок.
- README и руководство переписаны под реальную Kotlin-версию.
- Неиспользуемые текущие Python-исходники и метаданные PyInstaller убраны из корня; `BeforVersion` сохранён без изменений.

История Python-версии: [BeforVersion/PATCH_NOTES.md](BeforVersion/PATCH_NOTES.md).
