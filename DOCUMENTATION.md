# Документация ZI-Ops

[Вернуться к README](README.md) · [История изменений](BeforVersion/PATCH_NOTES.md)

## 1. Первый запуск

Запустите `ZI-Ops.exe` или `python zi_ops.py`. Откройте вкладку «Настройки». Для работы с файлами требуется FTP, для команд сервера — RCON. Эти подключения настраиваются отдельно.

Программа сохраняет настройки в `config.json` рядом с EXE или исходным файлом и загружает их при следующем запуске. Кнопка «Сохранить настройки» записывает текущие параметры; «Загрузить настройки» позволяет выбрать ранее сохранённый JSON-файл. При обычном закрытии программы настройки также сохраняются.

Пароли и API-ключ хранятся без шифрования. Не отправляйте `config.json` другим людям и не добавляйте его на GitHub.

## 2. Подключения

### FTP / FTPS

В «Настройках» заполните хост, порт, пользователя, пароль и базовый путь из панели хостинга. Если сервер требует защищённое подключение, включите FTPS. Поддерживается явный FTPS; неявный FTPS на порту 990 не поддерживается.

Базовый путь задаёт папку сервера, относительно которой выполняются файловые операции. Например, при базовом пути `/server/` путь `oxide/plugins/Example.cs` означает `/server/oxide/plugins/Example.cs`.

Проверьте путь по структуре файлов на своём хостинге. Значения по умолчанию не обязательно подходят вашему серверу.

### RCON

Укажите хост, RCON-порт и пароль. RCON-порт может отличаться от игрового и FTP-порта. Поле «Путь» нужно для нестандартного WebSocket-пути; если хостинг его не указывает, оставьте пустым. SSL/TLS включайте, если требуется соединение `wss://`.

Откройте вкладку «RCON», нажмите «Подключиться», затем «Проверить». Ответы и ошибки отображаются в консоли вкладки. Для RCON при запуске из исходников должен быть установлен `websocket-client`.

Некоторые серверы и хостинги ограничивают выполнение команд. Успешное подключение не гарантирует, что каждая команда разрешена.

## 3. Вайп через FTP

Вкладка «Вайп» удаляет файлы и очищает папки по заданным спискам. Перед операцией остановите сервер через панель хостинга и сохраните резервную копию нужных данных.

1. Проверьте «Файлы для удаления». Указывайте по одному пути на строку, относительно базового FTP-пути.
2. Проверьте «Папки для очистки». Их содержимое будет удалено, включая вложенные файлы и папки.
3. Если нужно сменить карту, включите «Сгенерировать новый seed и записать в server.cfg».
4. Выберите локальный шаблон server.cfg, скачанный с сервера. Кнопка «Проверить» показывает его содержимое. Локальный оригинал программа не изменяет.
5. Задайте seed и размер карты. При включённом «Случайный seed» для вайпа используется случайное значение.
6. При необходимости включите рестарт через RCON, задайте таймер и сообщение.
7. Запустите вайп и следите за логом. После завершения проверьте результат и запустите сервер, если он был остановлен через хостинг.

Если шаблон не указан, программа может скопировать seed в буфер обмена. Это не заменяет изменение настроек карты на сервере.

Кнопка «Важное» открывает памятку внутри вкладки. Некоторые серверы получают Seed и Map Size из панели хостинга или параметров запуска, а не из server.cfg. На таких серверах перенесите значения в соответствующие настройки вручную.

## 4. Карты RustMaps

Случайный seed можно получить без интернета. Генерация карты на RustMaps — отдельная операция, для которой нужен API-ключ.

1. Откройте [rustmaps.com](https://rustmaps.com) и войдите через Sign in.
2. Перейдите в [Dashboard](https://rustmaps.com/dashboard) и скопируйте API key.
3. Вставьте ключ в разделе «RustMaps API» вкладки «Настройки» и сохраните настройки.
4. Во вкладке «Вайп» задайте seed и размер, затем нажмите «Генерировать на RustMaps».

Ответ о принятии запроса означает, что запрос обработан сервисом, но карта ещё может генерироваться. Дождитесь готовности в Dashboard. Не отправляйте один запрос многократно в ожидании результата.

Время зависит от очереди и параметров карты: генерация может занять несколько минут или дольше. Прогресс смотрите в Dashboard. Доступные месячные лимиты и число одновременных генераций зависят от подписки. API описан в [документации RustMaps](https://api.rustmaps.com/docs/).

## 5. Судная ночь

Эта вкладка переключает набор файлов для вашего PVE/PVP-режима через FTP. Настройте её под используемые плагины.

Для включения укажите файлы, которые нужно удалить, локальный файл для загрузки и его удалённый путь. Затем нажмите «Включить судную ночь».

Для выключения задайте список удаления и два локальных файла с удалёнными путями для восстановления обычного режима. Затем нажмите «Выключить судную ночь».

Загрузка по существующему пути перезаписывает файл на сервере. Сохраните оригинальные плагины и конфигурации заранее. Итог каждой операции отображается в логе.

## 6. Команды RCON

После подключения используйте кнопки быстрых команд или поле ручного ввода. Команда отправляется кнопкой «Отправить» или клавишей Enter. Кнопка остановки отправляет `quit`, а рестарт — команду перезапуска сервера.

Блок «Быстрый вайп через RCON» меняет seed/worldsize и отправляет сохранение и рестарт. Файлы мира через FTP он не удаляет. Для очистки файлов используйте вкладку «Вайп».

Если команда не сработала, проверьте ответ в консоли, параметры подключения и права выполнения команд на хостинге.

## 7. Плагины

### Проверка версий

Укажите папку .cs-плагинов на сервере, например `oxide/plugins/`, и нажмите «Проверить версии». Программа скачивает файлы во временную папку, читает название, автора и версию из атрибута `Info` и сопоставляет их с настроенным списком обновления.

Для сравнения с последней версией нужна ссылка на страницу плагина в этом списке. Если версию определить не удалось, в таблице появляется `?`. Это не означает, что плагин обязательно устарел.

### Настройка обновления

В блоке обновления по URL добавьте строку для плагина. Укажите его название, прямую ссылку на скачивание .cs-файла, страницу версии и путь загрузки на сервере. Используйте ссылки из доверенного источника и сохраняйте копии изменённых плагинов перед обновлением.

Сохраните список. При обновлении программа скачивает файл и загружает его по заданному удалённому пути. Результат смотрите в логе вкладки.

### Кастомные плагины

Нажмите галочку в столбце «Кастомный», чтобы исключить плагин из действия «Обновить все». Отметка сохраняется в настройках. Используйте её для плагинов, код которых вы изменяли вручную.

### Сортировка

Нажатие на заголовки «Файл», «Название» и «Автор» сортирует текст; повторное нажатие меняет направление. Регистр букв не учитывается. Порядок: спецсимволы, цифры, русский алфавит, английский, остальные буквы.

«Кастомный» сначала показывает отмеченные плагины. «Статус» сначала показывает требующие обновления, затем актуальные, версии новее на сервере и неизвестные. Повторный клик разворачивает порядок. «Текущая» и «Последняя» не сортируются.

## 8. Если что-то не работает

| Проблема | Что проверить |
| --- | --- |
| FTP не подключается | Хост, порт, логин, пароль и требование FTPS. |
| Файл не найден или доступ запрещён | Базовый путь, путь файла и права FTP-пользователя. |
| RCON не подключается | RCON-порт, пароль, WebSocket-путь и необходимость SSL/TLS. |
| RCON подключён, но команда не работает | Ответ в консоли и ограничения хостинга. |
| RustMaps отклоняет запрос | API-ключ, лимиты аккаунта, seed и размер карты. |
| Последняя версия плагина — `?` | Наличие и доступность страницы версии, сопоставление с записью в списке. |

Для разбора ошибки сохраните текст из лога. Перед публикацией удалите из него пароли, API-ключи и другие данные доступа.
